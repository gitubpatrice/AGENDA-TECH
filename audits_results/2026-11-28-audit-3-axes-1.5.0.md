# Audit en trois axes — Agenda Tech 1.5.0 (2026-11-28)

## Périmètre

Delta `v1.4.0..f9589c0` (`main` après les PR #71 et #72) : fériés du Brésil (#70), écran des ponts, lint à zéro
avertissement, néerlandais. Calcul pur (`Bridges.kt`), un écran et sa route, des chaînes dans sept langues, les
textes publics (TERMS ×5, README ×2, fastlane, À propos). Aucune dépendance, aucune permission, aucune donnée
stockée touchée : dans les fichiers de build, seul `localeFilters` gagne `nl`. Audit en lecture seule, sur trois
axes : sécurité, performance et qualité, interface et branchements.

## Résultat

**Aucun constat critique ni élevé. Trois constats moyens, corrigés avant publication. Cinq constats faibles.**

| # | Gravité | Constat | Suite |
|---|---|---|---|
| M1 | Moyen | Écran des ponts : TalkBack lisait chaque pont en trois lignes séparées, à balayer une par une. | Corrigé (`19e4f1a`) : une ligne = un élément (`clearAndSetSemantics`), lu en une phrase. Relu sur le S9 dans l'arbre d'accessibilité : « Ascension. À poser : vendredi 7 mai. 4 jours de repos d'affilée : jeudi 6 mai – dimanche 9 mai ». |
| M2 | Moyen | Les dates abrégées (« jeu. 6 mai ») peuvent être mal lues par une voix (« jeu »), et le tiret du repos lu sans pause. | Corrigé avec M1 : la phrase lue porte les jours en toutes lettres (`EEEEdMMMM`). |
| M3 | Moyen | « Quatre ou cinq jours d'affilée » (CHANGELOG, changelogs store) : trop précis. Un ou deux jours posés entre deux repos donnent de trois jours (un mercredi entre deux fériés de milieu de semaine) à six (un mardi et un mercredi entre un lundi et un jeudi fériés). | Corrigé (`19e4f1a`) : « pour en faire un long week-end », la formule de la ligne des Réglages, dans les sept langues du store et dans le CHANGELOG. |

| L5 | Faible | `app/lint.xml` : l'exemption `OldTargetApi` ne disait pas quand la retirer. | Corrigé (`19e4f1a`) : « à retirer avec le passage de targetSdk à 36 ». |

## Points vérifiés sans constat

- **`Bridges.inYear`** : toutes les boucles finissent (le run vers l'avant est borné à trois jours ; les extensions
  du repos s'arrêtent au premier jour travaillé, et un samedi revient tous les sept jours) ; `.last()` ne peut pas
  lever d'exception (le jour avant un run est chômé par construction, celui d'après aussi pour un run court) ; la
  marge de 31 jours couvre toute extension ; un pont qui commence le 31 décembre appartient à son année, le repos
  qui déborde sur janvier compris ; pays avant leur première année vérifiée : liste vide.
- **Jours de report** (Royaume-Uni, États-Unis) : comptés comme chômés ; les fériés tombés un week-end ne sont pas
  donnés comme cause du pont ; l'écran dédoublonne les noms. Espagne (`unlessSunday`) : sans effet sur les ponts.
- **`BridgesViewModel`** : « aujourd'hui » vient de `DeviceZone` ; année par défaut (la suivante s'il ne reste rien) ;
  pays retiré pendant que l'écran est ouvert : texte « aucun pays », sans plantage ; calcul léger, sans E/S.
- **`BridgesScreen`** : clés de liste uniques et sauvegardables ; `ListFormatter` disponible dès l'API 26 (minSdk) ;
  `getBestDateTimePattern` compatible `DateTimeFormatter` dans les sept langues ; espaces insécables en
  `Char(0x00A0)` ; `LocalResources` ; icône décorative sans description.
- **Chaînes** : 458 clés dans les sept langues ; placeholders et pluriels identiques pour les nouvelles clés ;
  aucune apostrophe non échappée en néerlandais ; les renvois « sous Jours fériés » correspondent au libellé
  réel de chaque langue ; registres (Sie, Lei, usted, você, je) respectés.
- **Textes contre code** : onze pays, ponts « cette année et la suivante », Carnaval exclu, néerlandais non relu :
  exacts partout. La politique de confidentialité reste vraie sans modification (aucun réseau, ponts calculés sur
  le téléphone).
- **`app/lint.xml`** : chargé par défaut depuis la racine du module ; l'exemption ne couvre que
  `app/build.gradle.kts` ; les vérifications coupées ne signalent que des versions plus récentes
  (`RiskyLibrary`, `OutdatedLibrary`, `GradleCompatible` restent actives).
- **Chemins jumeaux** : `lightLineColor()` et `HolidayCountry.displayName()` n'existent plus qu'en un exemplaire,
  dans `ui/util`.

## Contrôles

Gate local sur `19e4f1a` : 775 tests unitaires sans échec, lint « No issues found », detekt, contrôle des
traductions et de la fiche store (six langues sur 458 clés ; chaque dossier fastlane, pt-BR compris, a son
`changelogs/65.txt` sous 500 caractères). Contrôles négatifs faits sur #71 : chaque nouveau test vu échouer contre
un défaut introduit exprès, puis passer.
